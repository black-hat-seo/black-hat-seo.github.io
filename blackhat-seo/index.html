个人观点

做安全的人，心术一定要正！

而想要用黑帽SEO（也包括其它黑产）这种旁门左道牟利的人，基本都是急功近利之人，即使短期能通过一些作弊手段达成目的，也绝不是长久之道。 因此，本人是绝对不会以黑帽SEO技术牟利的。（还有一些理由请见本人在白帽SEO中的观点）

之所以学习研究黑帽SEO技术，主要有2点原因：

1.由于SEO团队人员一些不规范（安全意识薄弱）的操作经常会让公司服务器被攻击，需要应急响应，知己知彼方能百战不殆。

2.公司站点被恶意镜像和泛站的时候需要我们组技术支持。

3.防止竞品网站恶意操作。

4.作为学习风险控制和反欺诈相关业务的一个知识点。

什么是黑帽SEO？

黑帽SEO，又称黑SEO，是一种为了提高SERP(Search Engine Results Page，搜索引擎结果页)排名所使用的作弊技巧，手段多是钻搜索引擎算法漏洞或通过伪造优质内容的方式对网站进行修改。 其本质是欺骗搜索引擎算法，让系统误认为经过其“优化”的网站是个“优质网站”。 (参考《2020网络黑灰产犯罪研究报告》 1.1)

由于白帽SEO优化的过程将会十分漫长，一个新站想要获取好的排名，往往需要花上几年时间做优化推广。因此一些想要快速提升自身网站排名的站长，便开始研究作SEO弊手法，从而诞生了黑帽SEO。 黑帽SEO是指通过作弊手段，让站点快速提升排名的一类SEO技术，或者说是黑客技术，比如说：黑链（暗链）、站群、网站劫持、桥页等，黑帽SEO能够快速提升排名，但毕竟是违规作弊行为，容易被K。（毕竟搜索引擎算法也在不断升级）

黑帽SEO 的英文为 Black Hat SEO，业内也常简称为“黑SEO”。它与白帽SEO 的出发点恰好相反：白帽SEO 以用户需求为中心、遵循搜索引擎的官方规范，追求长期而稳定的排名；黑帽SEO 则以“短、平、快”为目标，靠钻算法漏洞或伪造优质内容来短期冲榜。两者最直接的差别在于风险——白帽SEO 的排名建立在内容与体验之上，而黑帽SEO 一旦被搜索引擎识别（业内俗称被 K），轻则关键词排名与收录大幅下滑，重则整站从搜索结果中移除，恢复期往往需要 1～6 个月甚至更久，且未必能完全恢复。

常见黑帽SEO手法

忠告：鉴于部分黑SEO的优化手段和推广的业务都涉及非法产业链，建议研究相关技术者注意使用范围，切勿以身试法。

使用黑SEO手法有较高概率导致网站被K，故普通的SEO优化专员一般会注意避开使用黑帽SEO手法（当然也有部分人在边缘疯狂试验）。

0.关键词堆砌（已过时）

通过对网站标题或是页面进行大量地关键词堆砌，包括使用 长尾词、生僻词 等手段，实现网站在搜索引擎中权重排名的提升，从而将用户诱导进入目标网站。

1.挂黑链

一种是自己通过技术手段获得网站的webshell（有shell足够，并不需要提权），在网站页面中悄悄加上要做seo排名的网站的链接。

另一种是向黑产黑客批量购买webshell加链接，当然webshell的价格和其站点的权重呈正比。

2.网站劫持

网站为了在搜索界面抢占更有利的位置，往往会对一些权重较高的网站进行劫持，比如edu.cn或gov.cn结尾的网站。

3.泛站群

前提：在给做域名DNS解析的时候，选择了* 操作：进入服务器，可以借助泛二级域名建站工具，批量创建二级域名站点，从而实现站群的效果。

e.g.:
***.com
***.com
***.com

这里的“泛二级域名批量建站”即泛二级站群；与之相对的，借他人高权重域名的二级目录批量生成页面，属于泛目录泛内页站群；若以自有域名做“一域一站”的批量养站，则见独立站站群。

4.泛端口站群

先要获得操作目标站点的服务器权限，进入服务器之后，可以使用泛端口站群建设工具，批量创建泛端口站点。主要是在iis里面批量创建站点，绑定站点对应的端口。对于泛端口站点，一定要注意一些重要端口别占用了，否则可以导致服务器出错。一般泛站，用的比较多的是Dedecms程序。

e.g.:
***.com:30153
***.com:44849
***.com:15959

5.站中站(已废弃)

就是在权重高的网站中创建一个自己的网站，其实就是添加很多外链，蜘蛛会认为这些网站也是属于高权重网站的内容，因此权重也会比较高。但是由于这种做法太泛滥，导致百度修改了爬虫算法。

与“站中站”相近、至今仍被使用的形态是二级目录站内站，原理同样是借宿主站点权重，只是改由程序批量生成目录页面。

6.链轮

站点B是想要推广的网站，站点A是自己控制的外部网站，则可以先搞多个网站，做好自然排名，一层层外链下去，形成链轮。当想要推广某个网站时(比如站点B)，可以在所有外部网站上添加B的外链。谷歌爬虫已经修改了算法，百度尚可尝试，但效果已不复当年。

7.蜘蛛池

蜘蛛池是一种通过利用大型平台权重来获得搜索引擎收录以及排名的一种程序。原理可以理解为事先创建了一些站群，获取（豢养）了大量搜索引擎蜘蛛。当想要推广一个新的站点时，只需要将该站点以外链的形式添加到站群中，就能吸引蜘蛛爬取收录。

关于蜘蛛池的完整原理、识别与防护，可参见蜘蛛池一文。

8.寄生虫

寄生虫是黑帽SEO常用的一种方法，通过侵入别人网站，植入寄生虫程序，自动生成各种非法页面。之所以叫做寄生虫是因为能够自己触发生成，而不是一次生成，例如在访问网页的时候触发，自动生成页面且形成链轮等。。

动态寄生虫程序的“服务器端 / 目标端”结构，详见动态寄生虫。

9.URL结构含大量网址

通过对信息的堆积以及不合理的URL结构，黑SEO大量发布目标网站的地址，欺骗搜索引擎对此类网址进行优先抓取。

10.爬虫+仿站

爬虫这个不多说了，爬取页面或者数据都可用。

仿站简单解释下：仿站是针对目标网站进行仿制，仿站主要从页面风格和功能上进行仿制，我们通常所说的仿站是利用CMS（内容管理系统）做为网站的后台，而仿制的则是目标网站的静态模板。比如：一个高权重站点的镜像站点。

实际上这个方法目前看还是有效果的，从2019年遇到的一个案例分析可知：这类页面中绝大部分内容都是合法信息（高权重站点的信息页），仅在关键的logo和跳转URL换成了黑SEO优化目标的对应信息，搜索引擎自身的算法目前还无法精准检测出问题来。

这种“把目标站整站抓到自己域名下并保持同步”的做法，就是小偷镜像站群。

11.桥页/门页（Doorway Pages）

桥页（又称门页、跳转页）指专门为搜索引擎流量而制作的过渡性页面：页面本身内容单薄，甚至与用户真实需求无关，只是堆砌了大量热门关键词，用来在特定关键词下抢占排名。

用户从搜索结果点击进入后，页面会通过自动跳转（meta refresh、JavaScript 跳转、302 重定向等）把访客带到真正的目标站——通常是与搜索词无关的灰色行业站点。对搜索引擎而言它只是一张“门面”，对用户而言则是被“截流”后再转卖的一次流量。

12.斗蓬法/隐藏页面（Cloaking）

斗蓬法（Cloaking，又称隐藏页面、障眼法）指同一个 URL 针对不同访问者返回不同内容：对搜索引擎蜘蛛返回关键词丰富、看起来“高质量”的页面，对普通用户则返回广告、跳转或完全不同的页面。

实现方式通常是判断 User-Agent、访问 IP 段（搜索引擎蜘蛛的 IP 库）、Referer，或是否执行 JavaScript 等。它直接违背了“搜索引擎看到的页面应与用户看到的一致”这一基本原则，一旦被识别，站点极易被 K。

13.链接工厂（Link Farm）

链接工厂指由大量互相链接的网站（或页面）组成的一个链接网络，其唯一目的就是人为制造外链、传递权重，常见形式有站群、链轮、大批量二级域名互链等。

这些站点之间往往没有真实的主题关联，也不面向真实用户，纯粹为链接而存在。搜索引擎会通过链接拓扑、注册信息、内容相似度等特征识别出整个工厂并整体降权。

14.隐藏链接与隐藏文字（Hidden Text / Hidden Links）

隐藏链接/隐藏文字指在页面上放置普通用户看不到、但搜索引擎能读取的内容或链接：例如把文字颜色设为与背景相同、字号设为 0、用 CSS 定位移出可视区域（如 left:-9999px），或藏在图片 alt、noscript 标签中等。

典型场景是在一个正常页面里悄悄埋入大量目标关键词和指向黑产站点的“黑链”，既不影响页面观感，又能把权重导给目标站。这属于典型的作弊行为，被发现后轻则排名下滑，重则整站被 K。

15.假链接（Fake Links）

假链接指不通过真实的超链接语法传递权重，而是伪造出“链接”的视觉效果或抓取路径来欺骗算法。常见做法包括：用 JavaScript 或表单模拟跳转、把链接写在隐藏元素里、在评论区或用户资料页批量插入不可见的跳转地址等。

其目的是绕过搜索引擎对正常外链的识别与过滤机制，在“看起来没有外链”的情况下把流量与权重导向目标页面。

16.页面跳转与地址重定向（Redirect）

正常的重定向用于站点改版、域名更换等场景；黑帽手法则滥用 301/302、meta refresh、JavaScript location 跳转，把高权重页面“借用”过来导向灰产站点。

典型套路是先劫持或注册一个已有权重的域名，使其在搜索结果中被收录并取得排名，用户点击后再跳到目标站；或利用 302 跳转把权重“藏”在中间域名上，以规避检测。

17.网页劫持/网站镜像/偷换网页

网页劫持指通过入侵、DNS 劫持、CDN 或服务器配置缺陷篡改目标网站返回的内容：正常用户访问时展示黑产页面，或对搜索引擎展示被篡改后的页面。网站镜像则是把高权重站点的内容整体复制到黑产站点上，借其权重获取排名。

“偷换网页”多指在正常页面中偷偷替换 logo、跳转地址等关键元素，使其看起来仍是原站，实际却把流量与权重导向黑产目标（与第 10 条“爬虫+仿站”的做法类似，只是更隐蔽）。

18.PR劫持（PR Hijacking）

PR 指 Google 早期的 PageRank 值。PR 劫持指利用 301/302 重定向的漏洞，把高 PR 页面的权重“劫”到自己的站点上：例如临时用 302 跳转指向目标站，让搜索引擎把权重传递过去，事后再撤销。

这种做法依赖搜索引擎对重定向的处理规则，属于钻算法空子的老式手法，随着算法升级其效果已大幅衰减。

19.博客/论坛/留言本群发

指利用群发工具在大量博客评论、论坛帖、留言本、问答社区中批量留下带链接的垃圾内容，以制造外链、吸引蜘蛛抓取。

这类内容通常与主题无关、可读性极差，是早期最常见也最粗暴的作弊手段。如今主流平台普遍加了验证码、审核与 nofollow 处理，效果已十分有限，但它仍是黑产批量投放的低成本渠道。

20.垃圾链接（Link Spam）

垃圾链接是对上述多种手法的统称，泛指一切以操纵排名为目的、而非自然产生的外链，包括购买链接、群发评论链接、链接工厂、隐藏链接、互链交换等。

它们的共同特征是：链接双方缺乏真实的相关性，用户不会自然点击，纯粹为搜索引擎而存在。搜索引擎会通过链接质量、锚文本分布、链接增长曲线等维度进行识别和打击。

21.重复注册（Repeated Submission）

重复注册指把同一个网站（或内容完全相同、仅域名/URL 不同的多个镜像站）反复提交给搜索引擎，试图增加被收录与抓取的机会。

与之配套的还有“细微文字”、在同一页面大量重复关键词等做法，目的是在不改变实际内容的前提下抬高关键词密度与出现频次。这类手法对排名的提升微乎其微，反而容易触发搜索引擎的重复内容过滤。

以上手法并非彼此孤立：泛目录泛内页站群、泛二级站群、独立站站群负责批量产出页面，小偷镜像站群负责“搬运”他人内容，动态寄生虫以被入侵站点为宿主生成页面，二级目录站内站借自有站点权重放大收录，而这些页面最终往往依赖蜘蛛池加速被搜索引擎抓取。为便于逐一对照阅读，本站已将其中 7 类单独成篇，可点击上方链接或从左侧目录进入。
