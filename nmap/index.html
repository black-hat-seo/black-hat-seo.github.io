安装方式

  • MacOS: brew install nmap
  • CentOS: yum install nmap
  • Ubuntu: apt-get install nmap
  • Windows：官方exe安装包

常见扫描方式

指定端口快速探测开发端口和系统信息

nmap -p27000-28000 -vv -sV 10.0.4.154

指定IP全端口扫描

nmap -p- 10.0.0.41

扫描10000端口、操作系统

nmap -T4 -A <Target>

版本探测

nmap -sV <Target>

操作系统

nmap -O <Target>

实际高效使用方式

快速扫描网段内存活IP

nmap -oG - -sP 10.0.0.1/24

-sP    通过arp包判断局域网内的主机状态 
-oG    扫描结果使用Grep保存

实战

nmap 10.0.0.1 -p6379 -sV -Pn

-sV    表示进行版本检测，它将尝试确定每个扫描到的端口上正在运行的服务的版本信息。

-Pn    表示禁用主机发现，即不使用ping扫描来确定主机是否在线，而是直接进行端口扫描。

在不进行ping扫描的情况下，对目标主机进行端口扫描，并尝试确定每个扫描到的端口上正在运行的服务的版本信息。

使用自带或者第三方nse脚本

kali中nmap脚本目录在/usr/share/nmap/scripts/，可以将第三方和自研的nse脚本放在这里，方便执行

检查ms17-010

直接用nmap script

nmap -n -p445 --script smb-vuln-ms17-010 10.0.4.140/24 --open

-sP    通过arp包判断局域网内的主机状态 
-oG    扫描结果使用Grep保存

关于nmap和db_nmap

msf中可以直接用nmap，也可以用db_nmap。 使用db_nmap命令对我们的目标运行Nmap，然后对应的扫描结果将自动存储在我们的数据库中。 但若以后还希望将扫描结果导入另一个应用程序或框架，比如希望以 XML 格式导出扫描结果，即拥有所有三个 Nmap 输出（xml、grepable 和 normal），则需要使用Nmap。
